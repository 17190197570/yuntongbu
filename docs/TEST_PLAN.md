# 测试计划

## 结果记录原则

本文件描述验收项目，不宣称所有项目已经通过。以本次运行的构建日志、`scripts/test-integration.ps1` 输出和人工检查记录为准。真实 CFAPI 测试不能由普通文件复制或仅模拟回调的单元测试代替。

测试源和同步根必须放在本次测试新建的独立目录中。开始前记录 OS 版本、文件系统、Host 与 Agent 版本；清理时只处理本次测试创建且已经核对路径的目录。不要递归清理用户指定的源目录或未经核对的现有同步根。

## 第一阶段自动化验收

运行：

```powershell
.\scripts\build.ps1
.\scripts\test-integration.ps1
```

脚本应保留提供程序的日志并在失败时返回非零退出码，明确失败步骤。使用随机测试目录避免覆盖历史数据。至少包含以下验收：

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| CF-01 | 新建含中文目录、小文本和二进制数据的模拟源；启动 Host | 同步根成功注册并进入连接状态；源文件未被修改 |
| CF-02 | 只枚举同步根元数据，不读正文 | 完整目录结构与逻辑大小可见；文件为真实 CFAPI 占位，未预下载正文 |
| CF-03 | 使用普通文件读取 API 首次读占位文件 | 产生 `FETCH_DATA`；读取完成后与源 SHA-256 一致；CFAPI 显示完整水合 |
| CF-04 | 再次读取已完整水合文件 | 数据正确且使用本地缓存；停止提供程序后仍能读取已缓存内容 |
| CF-05 | 对干净水合文件执行 `release` | 占位仍在、正文被释放、源 SHA-256 与大小不变 |
| CF-06 | 再读已释放文件 | 再次触发水合，校验一致 |
| CF-07 | 修改本地水合文件后释放 | 拒绝释放；本地修改与源内容都保留，且没有强制标为已同步 |
| CF-08 | 源大小或修改时间在占位创建后发生变化 | 旧占位的水合或释放失败，不静默采用不匹配版本 |
| CF-09 | 在目标放入普通文件、使用其他根、改变文件身份 | 不接管或覆盖；失败有明确原因 |
| CF-10 | 参数包含根目录重叠、路径穿越、绝对 `--path`、ADS、重解析点 | 在危险操作发生前拒绝；根外内容不变 |
| CF-11 | 正常停止并按相同源和根重启 | 识别本软件身份；已存在的占位不被普通文件覆盖 |
| CF-12 | 停止后注销非空根、再对空的本软件根注销 | 非空时拒绝；保存本地修改并自行清空后可注销；源和其他根不受影响 |

对“未水合”的判断使用平台信息和实际磁盘占用，而不是只检查逻辑文件长度。注意读哈希本身会触发水合，因此 CF-02 不能对本地占位正文计算哈希。

## 第一阶段补充及人工验收

| 场景 | 预期 / 记录内容 |
| --- | --- |
| 资源管理器云朵状态 | 截图或人工记录占位、已下载、释放后状态；图标异常单独追踪，不以 API 成功替代 Shell 验收 |
| 双击文件 | 用实际关联应用打开，文件内容正确且程序无挂起；关闭应用后再验证释放 |
| 文件正在使用 | 用拒绝共享的句柄保持文件打开，再释放；必须拒绝且不丢数据 |
| 固定保留文件 | 固定状态可查询且拒绝释放；尚未实现固定命令时用平台工具设置或单列未验证 |
| 空文件与空目录 | 占位元数据、访问、重复启动和释放行为正确 |
| 超过 4 GB 文件 | 全文 SHA-256 一致、64 位偏移正确；记录峰值内存和耗时，不得整文件入内存 |
| 超大目录 | 记录条目数、启动耗时和内存；没有遗漏、崩溃或隐式正文下载 |
| 长路径、空格、中文、合法特殊字符 | 使用扩展路径测试；读写元数据、定位和水合一致，路径不经 shell 拼接 |
| 多文件并发读取 | 各文件内容正确；回调身份不混用；并发与取消可收敛 |
| 水合中取消 / 关闭读取程序 | 请求终止或安全完成；Host 仍可处理后续请求 |
| 水合中模拟源不可访问 | 返回明确失败并结束请求；不得用零填充或部分文件冒充成功 |
| Host 异常退出再启动 | 既有本地内容保留，注册与连接可恢复；没有失去身份的静默接管 |
| 磁盘空间不足 | 水合失败可观察；源不变，不误报完整水合 |
| 休眠与唤醒 | 提供程序恢复后仍可读取；超时请求不会永久卡住 |

## 后续阶段门槛

以下项目属于后续实现，不应在第一阶段报告为已完成：

- SMB：445 和替代端口、多连接、错误凭据、只读共享、目录不存在、协议协商失败、1219 会话冲突、凭据修改/清除、当前用户会话可见性。
- SMB 恢复：NAS 重启、会话过期、网络切换、断网、自动重连、超时进入离线，以及只清理本软件映射。
- 同步：创建/修改/重命名/删除、文件仍被写入、临时文件替换中断、上传后远端校验、两端同时修改、冲突副本和重试。
- 缓存：容量和访问时间规则、固定文件排除、未上传修改排除、目录释放、并发访问竞争。
- 归档：创建与修改时间均超过阈值、可靠创建时间缺失时跳过、先复制再 SHA-256 校验、归档失败保留源、验证后占位替换与记录持久化。
- 产品化：安装与卸载、用户会话后台 Agent、托盘、启动、自恢复、配置备份和日志脱敏。
