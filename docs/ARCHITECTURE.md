## 当前阶段：CFAPI 本地模拟原型

本次只验证需求中的第一步：让真实 Windows Cloud Files API 将本地模拟源的目录结构展示成占位文件，并在读取时水合，在验证安全后释放本地内容。

```text
Windows 资源管理器或普通文件读取程序
                    │ 本地 NTFS 文件访问
                    ▼
          本地 CloudDrive 同步根
                    │ Cloud Files API 回调
                    ▼
       CloudProviderHost（C++，当前用户）
          │         │             │
       注册根    占位与水合      安全释放
          │
          ▼ 只读、分块读取
       本地模拟源目录

CloudDrive.Agent（C#/.NET，当前用户）
          └── 校验命令参数、启动 Host、传递停止事件
```

原型中 C++ Host 直接读取模拟源。它还没有通过 IPC 向 Agent 请求文件数据；这个替换点属于后续 SMB 集成。Agent 与 Host 运行在同一登录用户会话中，暂不安装 LocalSystem 服务。

## 工程职责

| 位置 | 当前职责 |
| --- | --- |
| `src/CloudDrive.Core` | CLI 命令模型、绝对路径与相对路径参数校验 |
| `src/CloudDrive.Agent` | .NET 命令入口、Host 进程生命周期、环境诊断 |
| `src/CloudProviderHost` | 原生 CFAPI 注册、回调、占位信息、释放和注销 |
| `scripts` | 编译、演示、真实 CFAPI 集成验证入口 |
| `docs/REQUIREMENTS.zh-CN.md` | 用户原始完整需求，保留后续阶段约束 |

当前阶段不引入数据库、SMB 凭据、双向同步、缓存自动清理、归档、安装程序或完整 UI。占位身份由 CFAPI 持久保存；当前源目录与占位元数据的一致性检查不能替代未来的同步数据库。

## 数据生命周期

1. 首次启动要求同步根为空、位于本地 NTFS，并且与模拟源不相同、不互相包含。
2. Host 认领并注册同步根，递归扫描模拟源元数据，用 `CfCreatePlaceholders` 建立目录及文件占位。该步骤不复制文件正文。
3. 普通程序访问占位文件时，Windows 发出 `FETCH_DATA`。Host 验证文件身份和模拟源元数据后，分块读取源内容并通过 `CfExecute(TRANSFER_DATA)` 提交。
4. 使用 `FULL` 水合策略，Windows 在文件全文可用后完成用户读取。内存用量按固定缓冲区控制，不随文件大小线性增长。
5. 已水合内容保留在本地，再次读取使用缓存。Host 停止后，已有完整内容仍能读取；尚未水合内容不能依靠已停止的提供程序获取。
6. `release` 只释放单个已验证安全的文件：检查身份、独占访问、同步与固定状态、源版本和内容哈希，再调用 `CfDehydratePlaceholder`。
7. `unregister` 只注销本软件认领且为空的同步根；非空时拒绝。保存修改并清空本地测试条目由用户自行完成。

## 原型的安全边界

- 模拟源只读，测试和演示应使用独立的可重建目录。
- 不实现上传。对本地副本的修改必须保留，释放应拒绝该文件。
- 不实现远端版本更新。源大小、时间或身份与占位记录不符时拒绝继续使用旧版本映射，不能静默覆盖本地文件。
- 拒绝危险相对路径、重解析点及源/根目录重叠；也不接管其他提供程序的同步根或已有普通文件。
- 注册、连接和占位创建是不同操作；失败或中断可能留下已创建的占位文件，重启需要核对本软件的持久身份。
- 注销前先停止 Host。保留模拟源；注销并不保证脱水文件自动变成可独立使用的普通文件。

## 后续技术路线

按用户要求依次推进，每阶段通过核心验证后再扩展：

| 阶段 | 交付重点 | 前置验证 |
| --- | --- | --- |
| 1 | 本地模拟 CFAPI 占位、水合、释放 | 当前原型的真实 CFAPI 集成测试和资源管理器检查 |
| 2 | Windows 原生 SMB 连接、多连接、显式凭据、自定义端口 | 当前用户会话、凭据安全、映射所有权、版本与权限限制 |
| 3 | SMB 读取接入 CFAPI 水合 | Agent/Host 受控 IPC、分块传输、取消、断网、重连 |
| 4 | 双向同步与冲突 | 上传临时文件和校验、远端版本检测、禁止静默覆盖 |
| 5 | 缓存与归档 | 未上传内容不可释放；归档先复制、SHA-256 校验、再替换 |
| 6 | Windows 桌面产品化 | Fluent UI、托盘、安装、启动、备份与恢复 |

最终架构中，Agent 管理 SMB、任务队列、同步状态、缓存和归档；C++ Host 保持 CFAPI 专职边界。用户使用的是本地 NTFS 同步根，内部 SMB 映射只作为远端数据源。
