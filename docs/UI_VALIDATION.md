# 0.7.3 原生客户端界面优化

日期：2026-11-23。

## 实现范围

通过 Ant Design MCP 查询设计语言和设计令牌，采用主色 `#1677FF`、浅色背景、白色内容
表面、6/8 px 圆角和明确的操作层级。保留原有 WinForms、SMB、凭据管理、数据库及 CFAPI
架构；没有引入 React、浏览器登录或第三方 UI 运行时。

- 十个主页面改为分组左侧导航，选中态、页面标题与托盘跳转保持一致。
- 首页显示真实配置数量、后台状态和最后成功取得的文件/缓存统计；后台不可达时将
  后台统计显示为未知，不把离线状态涂成绿色；提供配置、健康中心和安全退出入口。
- NAS、文件夹映射和缓存策略采用分组卡片、统一输入框与焦点边框。
- 表格统一标题、行高、选中态和空记录提示；任务日志与最近活动采用独立行样式。
- 缓存、归档和健康中心子页使用统一页签；设置与运维划分客户端、启动和维护工具。
- 归档、产品设置、健康设置及诊断弹窗使用相同的字体、输入与按钮样式。
- 连接测试显示“通过/未通过”以及逐项结果，失败仍保留诊断代码。

控件保留原来的点击处理、键盘焦点、密码掩码、保存验证、取消操作及安全退出流程。
只读远端、上传试验和归档的原有功能边界继续显示；界面变化不代表未验收功能已经通过。

## 验证与复现

```powershell
./scripts/build.ps1 -Configuration Release -OutputDirectory artifacts/UI-0.7.3
./.tools/dotnet/dotnet.exe artifacts/UI-0.7.3/CloudDrive.Desktop.dll --smoke
```

Release 编译通过，0 警告、0 错误。界面冒烟使用独立临时数据库及虚构 NAS，检查：

- NAS 无映射独立保存、密码掩码/清空、多个映射共享凭据、删除映射后凭据保留。
- 十个实际侧边按钮在 1320×940 和最小 1180×850 窗口下逐个点击，检查选中态与标题。
- 导航可见性、连接及映射输入框几何布局、关闭隐藏到托盘和重新显示。
- 主页面、缓存子页面与设置弹窗截图；检查导航文字、输入、按钮换行和内容裁切。

截图及 `design-smoke/result.txt` 位于构建目录；未纳入公开源码。测试不访问用户 NAS，
不使用用户实际密码。当前截图验证为 Windows 96 DPI；更高 DPI、多显示器与读屏软件
仍需实际设备验收。9 组隔离回归（unit、connections、smb-host、phase2、phase3、cache、
archive、product、health）全部通过，结果见本地 `artifacts/validation/ui-0.7.3/`。
公开 CI 增加独立界面冒烟步骤；CI 只上传测试日志，不上传界面截图或用户运行数据。

0.7.2 记录的新文件上传 CFAPI `0x8007018B` 和实际 CFAPI 归档组合断言失败继续保留，
见 [SMB 宿主验证](SMB_HOST_VALIDATION.md)；本次界面改动不解决这两项问题。
