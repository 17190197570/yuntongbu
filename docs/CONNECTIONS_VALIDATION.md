## 新增专项覆盖

- NAS 无映射独立保存、不创建文件夹、共用凭据引用、不同映射独立文件 ID。
- 账号修改传播、源/根/存储重定向保护、映射根重叠保护。
- 实际 schema 5 迁移、原始 JSON / FileId / 版本 / 凭据引用保留、预升级备份及重开幂等。
- 实际 v5 ZIP 恢复迁移；无映射 NAS 的新配置不能被旧备份覆盖。
- 显式创建 Unicode 子目录、无创建许可保护、取消后无新增目录、重复创建幂等。
- 非空未受管本地目录、普通文件占位、Windows junction、扩展路径别名的真实目录身份检查。
- 扫描占用时维护拒绝、失败后锁释放、删除映射保留 Windows 凭据、NAS 引用删除保护。
- 仅 NAS 配置的卸载保护、健康探测不伪造 CFAPI 重连、真实 SQLite 完整性和关联检查。

最初 UI 烟测发现维护锁重复获取，已修复为在取得维护锁后直接调用原 Mapper 的受管断开方法；后续完整页面烟测通过。截图来自该通过的构建。最终补充的物理路径身份保护及最小窗口截图检查代码分别处于“专项通过”和“桌面加载被策略阻断”状态，不用旧截图代替最终启动验收。

## 待真实环境验收

真实 NAS 的 445 登录、自定义端口/UAC、用户名密码认证、共享与子目录创建、多个映射同时工作、同服务器不同凭据冲突、真实文件水合/释放、NAS 断网恢复、休眠/网络切换、Windows 重启均未验收。TCP 或本地夹具通过不能替代这些项目。

当前普通权限页面创建自定义端口远端目录仍受原生 UAC 限制；可离线保存映射，并使用原受控启动入口连接已存在的远端目录。未实现完整双向同步、已索引映射的原地改源和非空受管根的安全解除绑定。正式签名、真实安装/升级/卸载与更新发布仍未验收。
