开发包采用.NET10 win-x64自包含发布，Host为MSVC静态运行库。版本统一由Directory.Build.props管理。原型Host的帮助文本仍保留原型描述，不应当作正式产品版本凭据。

本机最新交付回归中，Windows应用控制阻止新构建的CloudProviderHost.exe（WinError4551）及Bootstrap.dll（0x800711C7）。较早同日回归曾成功执行实际CFAPI和空Agent崩溃恢复；两份记录分开保存，最新环境不能标为运行通过。详见[验证报告](PHASE6_VALIDATION.md)。不改变系统策略、不复制或改名以逃避校验。

必须补做：不同非管理员用户、多登录会话隔离、登录启动/注销、断网与唤醒、10万文件、并发NAS、24/72小时内存/句柄曲线、真实签名正向验证、安装修复升级卸载与失败回滚VM矩阵、非空同步根的两种卸载方案。

发布流程：构建 → 自动化回归 → 实际CFAPI → 真实SMB → 自包含发布 → 签名自有二进制 → WiX打包 → MSI签名/时间戳 → 独立验签 → VM安装升级卸载 → 发布。缺少证书和发布地址时仅允许标记为开发包，绝不创建假签名或自动开放不可信更新。
