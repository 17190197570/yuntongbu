# CloudDrive Lite 0.6.0 开发包安装与使用

日期：2026-11-20。此包未签名，尚未通过干净系统的安装/升级/卸载验收。Windows 应用控制可能阻止运行；应使用组织认可的开发/签名环境，不关闭安全策略。完整双向同步及真实 NAS 仍未验收，已有文件保持只读。

## 安装前

使用 Windows x64 build 19041 或更新版本，本地同步根必须为 NTFS。主要测试系统为 Windows 11 build 26200。ARM64 与其他 Windows 版本未验收。自定义 SMB 端口需要 build 26100 及对应 New-SmbMapping TcpPort 参数；普通445连接不自动提权。

开发 MSI 已包含 .NET 10 x64 和桌面运行时；原生 Host 使用静态 C++ 运行库。无需另做运行环境下载引导程序。CloudDrive.Bootstrap.exe 是安装后的运行入口，不是 WiX Burn 安装引导程序。

## 安装和首次启动

1. 核对 ReleaseNotes.md 与 SHA256SUMS.txt。SHA-256 仅确认字节完整性，不证明发布者来源。
2. 打开 CloudDriveLite-x64.msi。首期为当前用户安装，程序位于 LocalAppData 的 Programs/CloudDrive Lite，普通安装不使用 LocalSystem 服务。
3. 从开始菜单打开 CloudDrive Lite。初始化数据库和目录由程序完成；安装/初始化不连接 NAS、不自动迁移文件。
4. 在“SMB连接管理”填写服务器、共享、子目录、账号和本地同步根，再保存密码。密码只交给 Windows 凭据管理器。
5. 运行连接测试、查看逐项诊断，再扫描目录、启动 Agent。自定义端口使用单独的同用户 UAC 操作。

## 窗口和后台

关闭主窗口会隐藏到系统托盘，Bootstrap 与 Agent 继续运行。双击托盘或再次打开开始菜单入口会显示窗口。托盘提供同步认领暂停/恢复、自动归档暂停/恢复、重新连接、日志与安全退出。

“暂停同步认领”只暂停新增上传试验认领；当前文件操作安全收尾，读取和水合仍可继续。它不代表完整双向同步已实现，也不会取消用户的文件读取。

首页读取后台缓存状态。CFAPI就绪、SMB在线、数据库健康是不同指标；状态时间需要一起查看。托盘文本有 Windows 长度限制，完整信息在首页。窗口采用统一的原生 WinForms 样式，尚未更换为 WinUI 3/完整 Fluent 控件库。

## 自动启动、缓存和归档

在连接页面启用“Windows登录时启动 Agent”，只修改当前用户启动项；设置页可以调整登录延迟。默认没有启用登录启动。若启用，Bootstrap 延迟启动后台并加载 AutoConnect 的普通端口连接；自定义端口仍需明确UAC操作。

缓存清理和自动归档默认关闭。归档遵循创建时间与修改时间均严格早于阈值的 AND 条件；默认180天。先预览，再在专用测试数据上执行。归档完成会在多次校验后删除源远端文件，绝非普通备份复制。

## 更新

本开发包没有发布证书或可信更新地址。检查更新会明确拒绝，不能通过设置普通URL或SHA-256绕过签名要求。

后续正式渠道需要固定 RSA3072 或更强清单公钥、允许的HTTPS域名、发布者证书SHA-256，以及签名清单。可信清单验签、有效期/渠道/序号检查、流式下载、进度/取消/重试、包哈希、WinVerifyTrust 与发布者匹配都通过后，才允许用户确认安装。取消下载会保留部分文件以便续传。

升级前协调停止后台、在线备份数据库，安装过程不清空同步根、队列、缓存、凭据或存储映射。需要重启的安装结果单独记录；不自动强制重启。尚未完成真实签名正向测试、升级VM矩阵和失败回滚演练。

## 备份、诊断与退出

“设置与运维”可手动备份、预览并恢复备份、预览脱敏诊断和执行卸载检查。后台每天一次备份、默认保留7份；备份和日志策略可调整，日志策略在Agent重启后应用。备份可能含NAS地址和文件映射，应自行安全保管；它不含凭据密码，也不含文件正文。

明确退出会停止接受新任务并等待安全收尾。超过界面等待时间会保留窗口与后台，不强制结束操作。完整水合的缓存保持在本地；仅联机文件在提供程序停止后不能继续从远端读取。

## 卸载限制

本开发版实现了卸载检查与 MSI 阻断：配置了同步根、有未完成任务、孤立映射或状态异常时，拒绝直接移除程序。不会删除 NAS、其他 SMB 映射或同步目录。

任务书的方案A（下载并转换非空根为普通文件）和方案B（核验后清理占位、保留选定缓存）尚未实现。存在受管根时应取消卸载，保留软件及数据。不要手动删除程序来绕开检查。未配置连接且无任务/映射时，MSI可进入移除流程，用户数据和备份默认保留；该流程仍待干净VM实测。
