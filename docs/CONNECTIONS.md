# NAS 连接与文件夹映射（0.7.1）

2026-11-20。本次在既有工程中拆分配置与页面，保留原 CFAPI 模块及其文件身份。源码版本 0.7.1，SQLite schema 6。第六阶段 `artifacts/Release` 与第七阶段 `artifacts/Phase7` 为历史封存包，不包含本次改动。

## 使用页面

“SMB 连接管理”仅维护 NAS 本身，不要求本地目录、远端子目录或连接名称。

| 字段 | 是否必填 | 填写示例 |
| --- | --- | --- |
| 连接地址 | 是 | `192.168.1.10` 或 NAS 域名，不带 `\\`、端口或目录 |
| 端口 | 是，默认 445 | `445` |
| 共享名称 | 是 | NAS 中实际开启 SMB 的共享，如 `data`；不填子目录 |
| 用户名 | 是 | NAS 的登录用户名 |
| 密码 | 首次必填 | 只在本机页面输入；编辑留空保留已保存密码 |
| 域 / 工作组 | 否 | 需要时填 `WORKGROUP` 或实际域名 |

点击“保存 NAS”，然后“连接测试”。测试使用已保存的参数，界面改动后需要重新保存。此处不创建目录、不扫描文件，也不建立 CFAPI 根。密码仅通过 Windows 凭据管理器保存，不写入 SQLite、日志或进程参数。

“文件夹映射”可以以后再维护：新增映射 → 选择已保存 NAS → 填本地文件夹和共享内远端子目录 → 保存。远端子目录留空表示共享根。一个 NAS 可供多个映射使用，不需要重复输入密码。

例如：NAS `192.168.1.10:445` / 共享 `data`，映射本地 `D:\CloudDrive\文档` 到远端 `部门\文档`，最终数据来源是 `\\192.168.1.10\data\部门\文档`。

- 未勾选“创建缺失目录”：只保存映射，可离线设置，不访问 NAS、不创建目录。尚未存在的目录不代表连接已验证。
- 勾选后保存：经原生 SMB 客户端连接已存在的共享，检查目录链，再逐级创建远端子目录和本地目录。需要 NAS 创建目录权限。共享本身不会自动创建。
- 新映射本地文件夹须为空或尚未存在，并位于本地 NTFS 固定磁盘。已有映射的非空目录需通过原 CFAPI 根身份检查。
- 创建是独立的维护操作；失败、取消或断网可能保留已经创建的目录，不会为回滚而删除目录或用户文件。已存在的普通文件、目录联接及符号链接会触发保护。
- 保存后按需点击“扫描目录”和“启动 Agent”，复用原来的索引、占位及流式按需读取。自动连接属于映射设置。

## 兼容及数据流

`StorageConnections` 保存 NAS 地址、共享、账号与凭据引用；`FolderMappings` 保存执行映射 ID 与 NAS ID 的关联。原 `connections` 行继续保存执行所需配置，因此既有扫描、占位、水合、缓存和归档入口保持可用。

旧 schema 5 升级前先作 SQLite 在线备份。每条旧连接建立对应 NAS 配置及关联，原连接 ID、配置 JSON、同步根、文件 ID、索引版本和凭据引用保留。`SmbConnection.StorageId` 为可选字段，旧记录仍按原 ID 查凭据；新映射按所属 NAS ID 查凭据。

按需读取依旧是：占位身份 → 映射 ID / 文件 ID → SQLite 版本及路径 → 所属 NAS 凭据 → 原生 SMB 映射 → 共享内子目录 → 原有分块 CFAPI 数据传输。未重新实现 C++ 回调、占位、水合或释放模块。

编辑 NAS 会更新其关联映射的账号参数。界面先安全停止相关 Agent，再取得原有 Agent、扫描、缓存和归档操作锁；有工作未完成时拒绝修改。密码变化后由用户从映射页重新启动。删除一个未使用的映射不再删除共用 NAS 凭据；仍被映射引用的 NAS 不允许删除。受管根、索引和恢复历史的删除保护继续生效。

已索引或存在同步、缓存、归档历史的映射不能直接更换 NAS、共享、远端路径或本地根，以免旧占位身份指向错误内容。当前须新增映射，尚未提供原地迁移及非空根解除绑定向导。

schema 4 / 5 备份在临时副本中迁移到 schema 6。兼容检查包含新增两表，NAS 尚无映射时也不能通过恢复覆盖较新的配置。卸载检查和健康检查同时识别仅保存 NAS 的情况。

## 当前限制

- 未收到真实 NAS 配置或凭据，实际认证、目录创建、跨共享、断网恢复、休眠/重启及多映射 NAS 验收未执行。
- 自定义端口仍需 Windows 版本、`New-SmbMapping.TcpPort` 及当前令牌支持。普通 445 不申请管理员权限。映射可离线保存后从原受控 UAC Agent 入口启动；普通权限页面不能直接创建自定义端口远端目录，当前需该目录预先存在或在合适的受控管理员环境中维护。没有绕过策略或自动转回 445。
- 当前机器的 PowerShell 策略可能阻止 SmbShare 模块加载；此时连接测试明确报告 `SecurityPolicy`，TCP 成功不算 SMB 成功。未修改执行策略、应用控制或其他软件映射。
- 完整双向同步仍未实现。已有文件保持只读；新增上传试验的真实 CFAPI 转换依旧有已知 `0x8007018B` 失败。
- 源码与构建目录为未签名开发版本，正式签名、安装升级及发布渠道仍未验收。
